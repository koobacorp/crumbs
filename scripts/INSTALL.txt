CRUMBS v1.0 — macOS install

1. Unzip this folder somewhere you can find it.
2. Copy CRUMBS.vst3 into:
   Macintosh HD / Library / Audio / Plug-Ins / VST3
   or, for your user only:
   ~/Library/Audio/Plug-Ins/VST3
3. Rescan plugins in FL Studio (or restart it).

Nothing is installed automatically. You can also run install_mac.sh, which only copies the VST3 into those folders after asking.
